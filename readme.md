# NCFG

## Быстрый старт

```bash
npm run dev
```

Это канонический режим: локальные Next.js frontend и `app/api` backend с
production Strapi только для чтения. Подробности и остальные профили — в
[`DEVELOPMENT.md`](./DEVELOPMENT.md).

Документация для разработки:
- Локальный запуск и диагностика: `DEVELOPMENT.md`
- Практики и стандарты кода: `ENGINEERING.md`
- Git/PR/коммиты: `CONTRIBUTING.md`
- Онбординг нового разработчика (clone -> dev -> commit -> PR): `ONBOARDING.md`

Фронтенд: `apps/web` (Next.js)  
CMS: `apps/cms` (Strapi)
