Following the user's request to reconsider desktop animation, the current motion proposal replaces the bottom-up mask and entrance stagger with a whole-photo refocus: seven seconds of active viewing, 180ms outgoing blur to 7px/scale 1.035, an opaque frame cut, then 420ms resolving the new photo to sharp/original scale. Below 1200px, a centered copy block up to 900px wide within an 1100px maximum compact layout places the headline, lead and CTA on one central axis above a compact horizontal carousel with nine employees. The lead retains a readable 28em maximum width and uses balanced wrapping; phone CTA remains full-width. Native overflow supports swipe; arrow keys, Home and End support keyboard navigation. All visible pause/resume and paging buttons and the controls row’s spacing are removed at the user’s request. The [asset manifest](portrait-assets-v3.json) lists all nine outputs, source paths, dimensions and byte counts.
