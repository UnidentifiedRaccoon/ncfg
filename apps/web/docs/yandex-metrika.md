## Ключевые отчёты

### Воронка конверсии

**Отчёты → Конверсии**

Следить за цепочкой:

```
cta_click → lead_form_start → lead_form_submit
```

- `cta_click` высокий, `lead_form_start` низкий → люди не доскролливают до формы
- `lead_form_start` высокий, `lead_form_submit` низкий → проблема в самой форме (поля, валидация, доверие)

### Диагностика

```
diagnostic_step (step: 1) → step 2 → ... → diagnostic_complete
```

Отчёты → Параметры визитов → фильтр по `diagnostic_step` покажет, на каком шаге уходят.

### Контент

```
blog_category_click → scroll_50 → scroll_100 → question_form_expand
```

Если `scroll_50` низкий на статьях — контент не удерживает читателя.

## Сегменты посетителей

**Отчёты → Посетители → Создать сегмент**

Создать и сохранить:

| Сегмент | Условие | Зачем |
|---------|---------|-------|
| Горячие лиды | Достигли `lead_form_submit` | Анализ пути до конверсии |
| Тёплые | Достигли `lead_form_start`, но НЕ `lead_form_submit` | Понять, почему бросают форму |
| Интересующиеся услугами | Достигли `service_click` | Какие услуги смотрят |
| Читатели блога | Достигли `scroll_75` на `/blog/*` | Вовлечённая аудитория |
| Из диагностики | Достигли `diagnostic_complete` | Качество лидов из диагностики |
| С рекламы | Источник = «Рекламные системы» | ROI рекламных кампаний |
| 404-ошибки | Достигли `page_not_found` | Битые ссылки, плохой UX |

## Техническая реализация

### Файлы аналитики

| Файл | Назначение |
|------|-----------|
| `shared/lib/ym.ts` | Реестр целей `YM_GOALS` + функция `reachGoal()` |
| `shared/lib/utm.ts` | Захват UTM-параметров в sessionStorage |
| `shared/ui/YandexMetrikaRouteTracker.tsx` | Отслеживание переходов между страницами |
| `shared/ui/YandexMetrikaGoalTracker.tsx` | Делегированный обработчик `data-ym-goal` для server-компонентов |
| `shared/ui/ScrollDepthTracker.tsx` | Глубина прокрутки (25/50/75/100%) |
| `shared/ui/UtmCapture.tsx` | Захват UTM при первом визите |
| `shared/ui/NotFoundTracker.tsx` | Трекинг 404-страницы |

### Два способа трекинга

1. **Прямой вызов** — в client-компонентах (`"use client"`):
   ```ts
   import { reachGoal, YM_GOALS } from "@/shared/lib/ym";
   reachGoal(YM_GOALS.LEAD_FORM_SUBMIT, { utm_source: "google" });
   ```

2. **Data-атрибут** — в server-компонентах (без `"use client"`):
   ```html
   <a href="tel:..." data-ym-goal="phone_click">
   ```
   Обрабатывается `YandexMetrikaGoalTracker` через делегированный `click` listener.

### Добавление новой цели

1. Добавить идентификатор в `YM_GOALS` в `shared/lib/ym.ts`
2. Добавить `reachGoal()` или `data-ym-goal` в нужный компонент
3. Создать цель в Метрике: Настройка → Цели → JavaScript-событие
4. Проверить с `?_ym_debug=1`
