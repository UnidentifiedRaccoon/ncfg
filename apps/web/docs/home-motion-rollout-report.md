Исправлены два случая доступности: неподвижный курсор больше не меняет направление колоды при прокрутке с клавиатуры; явный CSS-режим `data-enhanced="false"` немедленно убирает декоративные трансформации при живом переключении reduced motion, включая WebKit и изображение вне экрана.

Сцена находится в `app/_components/HomeMotionScene`. Временный маршрут, панель сравнения, callback варианта в `HomePageContent` и запись эксперимента удалены. `/experiments` и лаборатория сезонного офера сохранены.

## Локальный запуск и ограничения

Turbopack в этой сессии повторно зависал после загрузок главной: процесс Next.js достигал более 11 ГБ памяти. Перезапуск и перенос генерируемого dev-кеша не устранили повторение. В штатный launcher добавлен необязательный выбор `NCFG_DEV_BUNDLER=webpack`, описанный в [DEVELOPMENT.md](../../../DEVELOPMENT.md). Production-сборка и профиль доступа к CMS не менялись.

Локальная разработка оставлена запущенной командой:

```bash
NCFG_YC_PROFILE=default NCFG_DEV_BUNDLER=webpack npm run dev
```

Launcher подтвердил `READY`. Strapi используется только для чтения, записи и внешние интеграции отключены.

Доступ к production Strapi остаётся нестабильным: периодически возникает connect timeout. В некоторых живых прогонах штатный fallback убирал услуги или новости; такие пропуски перечислены в `missingCms`, а полный набор блоков проверен отдельно. Полная production-сборка, сравнительные LCP/CLS/FPS и публикация этого расширения не выполнялись. Остаток общей приёмки предыдущей миграции описан в [motion-migration-report.md](motion-migration-report.md).
