# NCFG Design System

Визуальный стиль корпоративного сайта NCFG. Вдохновлён подходом Т-Банка и Альфа-Банка: простой, понятный, визуально приятный.

## Brand Identity

### Позиционирование
- **Отрасль:** Консалтинг, финансы
- **Характер:** Надёжный, профессиональный, современный
- **Ощущение:** Доверие, ясность, экспертиза

### Визуальные принципы
1. **Простота** — минимум декоративных элементов, фокус на контенте
2. **Иерархия** — чёткое разделение важного и второстепенного
3. **Воздух** — щедрые отступы, не перегружаем экран
4. **Контраст** — электрический акцент выделяет ключевые действия

## Typography

### Шрифтовой стек

```css
--font-sans: "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto,
             "Helvetica Neue", Arial, sans-serif;
--font-mono: "JetBrains Mono", "Fira Code", Consolas, monospace;
```

**Почему Inter:**
- Оптимизирован для экранов, отличная читаемость

### Header (Navigation)

Цель: 4 ключевых раздела + один primary CTA, в “банковском” стиле (T-Bank / Альфа): чистый фон, стеклянный dock, типографика и аккуратные пилюли.

**Состав:**
- Logo → `/` + wordmark `НЦФГ` (крупные буквы)
- Links: `/individuals`, `/companies`, `/about`, `/blog`
- CTA: `#lead-form` (на страницах блога — `/#lead-form`)
- Mobile/tablet: burger + dropdown panel

**Текущая реализация (фиксированная):**
- `dock`: стеклянная капсула‑dock, без внешнего grid‑фона; CTA в pill‑форме (`rounded-full`).
  - Авто-инверсия на границе Hero: пока Hero “под” хедером — тёмный glass (hero-tone), после — светлый glass (surface-tone).
  - Граница определяется sentinel-элементом `data-header-hero-end` внутри `HeroLayout`.
  - В `surface-tone` hover верхнего уровня использует `#F1F5F9`, а текущая страница и раскрытое меню «Компаниям» получают прозрачную капсулу с inset-контуром Deep Navy 2 px; hover/focus внутри выбранного пункта добавляет Deep Navy state-layer 6%, keyboard focus сохраняет внешний контур `#3B82F6`.
- Раскрытые слои следуют тому же `dock-tone` без отдельного переключателя:
  - `hero-tone` → специально собранный тёмный навигатор (`#0B1324` / `#0F1C30`, светлый текст, cyan focus outline);
  - `surface-tone` → светлый навигатор на белых и gray-50 поверхностях; selected-направление и HR-оффер в покое используют одну blue-gray поверхность `#EAF1F8`, а при hover HR становится насыщеннее (`#DCEAF7`);
  - при прокрутке тема открытого меню меняется вместе с dock, сохраняя выбранное направление, открытый аккордеон и focus.
- «Компаниям» раскрывает тихий навигатор корпоративных услуг:
  - desktop (`xl+`): `/companies` остаётся прямой ссылкой, соседний disclosure управляет меню; hover/focus также раскрывают его;
  - tablet: направления слева, предложения справа внутри compact-меню;
  - mobile: направления раскрываются inline-аккордеонами сразу под строкой «Компаниям»;
  - desktop/tablet: направления образуют вертикальный tablist; стрелки, Home и End меняют направление, а Tab переводит фокус в его список услуг;
  - HR-оффер и ссылка «Все услуги» образуют полноширинное завершение левой колонки/мобильного списка;
  - hover/focus направления сразу использует ту же базовую поверхность, что и выбранное направление: navy в dark-theme и светлый blue-gray в light-theme; поверх неё добавляется мягкий state-layer без промежуточного цвета, бокового маркера и анимации при смене hover → selected;
  - ссылка «Все услуги» повторяет состояние обычного направления на desktop/tablet и закрытого аккордеона на mobile; focus добавляет theme-safe контур (`#3B82F6` light, `#8FC7EE` dark);
  - мягкий state-layer сохраняется для поверхностей без автоматической смены выбранного пункта: Ocean Blue 6–7% в light-theme и белый 7% в dark-theme;
  - Escape последовательно закрывает подменю и compact-меню, focus возвращается к управляющей кнопке.
- Категории и услуги читаются из Strapi облегчённым запросом; при недоступности CMS используется проверенный локальный fallback, чтобы основная навигация не исчезала.

### Footer

Цель: футер в духе современного банкинга (T-Bank / Альфа), который визуально **продолжает Hero**. Без “простыни”: контент собираем в один цельный `slab` с деликатными разделителями (без эффекта “стекла” на всю панель).

**Структура (общая):**
- Subtle CTA-ряд: «Консультация бесплатно» + кнопка на `/#lead-form` + pill‑контакты (телефон/почта).
- Колонки: бренд/контакты, навигация, соцсети + юр. ссылки, юр. документы (если есть).
- Нижняя полоса: `© {years} {shortName}.` + 1–2 строки юридического текста.

**Текущая реализация (фиксированная):**
- `hero`: фон как `HeroLayout` (`#050B16` + glow + grid), панель цельная `bg-[#0B1324]` (без blur).

### Experts (Capital Desk)

Блок «Наши эксперты» — витрина **внешних** экспертов (без дублей с «Наша команда»). Выбран паттерн `Capital Desk`: одна ведущая карточка + компактная сетка. Карточки статичные: только hover-эффекты, без клика/модалов.

**Stage (canvas):**
- Outer: `rounded-2xl ... p-px` (мягкая градиентная окантовка)
- Inner: `relative rounded-2xl bg-[#F8FAFC] p-4 md:p-6 overflow-hidden`
- Atmosphere: лёгкий grid-слой (`opacity ~0.05`) + один glow `rgba(88,168,224,0.25)`

**Layout:**
- Mobile: горизонтальный скролл со snap, первая карточка `min-w-[320px]` (featured), остальные `min-w-[280px]`, fade-края слева/справа
- `md+`:
  - `1` эксперт: только `FeaturedExpertCard` по центру (`max-w-3xl`)
  - `2+` эксперта: split `grid-cols-[1.08fr_0.92fr]` (слева featured, справа compact grid)

**Cards:**
- `FeaturedExpertCard`: `rounded-2xl`, крупный аватар `80px`, top accent line + постоянный left rail, усиленная тень
- `CompactExpertCard`: `rounded-xl`, glass-основа (`bg-white/85`), hairline сверху + left rail на hover
- Hover: `hover:-translate-y-1`, акцент через `border-[#3B82F6]/25..30`

**Правило по акценту:** `#58A8E0` используется только декоративно (градиенты/рейлы), не как основной цвет текста внутри карточек.

```tsx
/* Mobile scroll */
```

### FAQ (Частые вопросы)

Цель: закрыть 6–10 популярных вопросов “банковским” образом (быстро, понятно, с воздухом) и мягко подвести к заявке.

**Композиция (общее):**
- Секция: белый фон, стандартный `Section` заголовок (H2) + опциональный lead.
- Контейнер: **одна** основная карточка (аккордеон) без внешней рамки-обёртки, чтобы не было эффекта “карточка в карточке”.
- Атмосфера: деликатный grid + 1–2 glow размещаем **внутри** карточки (через абсолютный overlay) или за ней, но без видимого внешнего контура.
- Внутри: аккордеон-список в одном stage-контейнере.

**Вариант A — Stage Accordion (рекомендуем):**
- Accordion card (единый контейнер, без внешнего “stage”):
  - Base: `relative overflow-hidden rounded-2xl border border-[#E2E8F0]/70 bg-white/80 backdrop-blur-sm shadow-sm`
  - Atmosphere overlay: grid `opacity ~0.05` + 1–2 glow (Ocean/Accent на низкой непрозрачности)
- Item:
  - Семантика: `<details><summary>` (без JS, good for performance)
  - Open-state: лёгкая подложка + hairline highlight сверху + акцентный rail слева (градиент `#58A8E0 → #3B82F6`)
  - Toggle icon: chevron (rotate 180 на open)
- Footer CTA: строка внутри карточки, отделена `border-t`, кнопка `secondary` на `#lead-form`

**Правила текста:**
- Вопрос: 1 строка (макс 2), без вводных слов (“подскажите”, “скажите пожалуйста”).
- Ответ: 2–4 коротких предложения. Если нужен CTA, делаем один линк или одну secondary-кнопку.

**A11y:**
- `<details><summary>` обеспечивает базовую доступность и управление с клавиатуры.
- `focus-visible` не отключаем.
- Нативный marker у `summary` скрываем и рисуем свой icon.

**API (widgets/FAQ):**
```tsx
<FAQ title="Частые вопросы" items={faqItems} />
```

### LeadForm (Primary CTA Section)

Главный блок-конвертер «Оставить заявку» в духе современного банкинга: светлая секция с “атмосферой” + выраженная карточка формы.

**Композиция**
- Фон секции: `Gray 50 (#F8FAFC)` + очень лёгкий grid + 2–3 `radial glow` пятна (`Ocean Blue` / `Electric Cyan`) на низкой непрозрачности.
- Контент: `lg` 2 колонки (слева ценность и “что дальше”, справа карточка формы).
- Карточка формы: `rounded-2xl`, `border` + мягкая “банковская” тень, тонкая акцентная линия сверху (градиент `Electric Cyan → Ocean Blue`).

**Поля формы**
- Inputs/textarea: `rounded-md (8px)` как в токенах (не `rounded-lg`).
- Focus: `Ocean Blue` border + мягкий ring.

- Линия и соединители статичны: геометрия процесса доступна сразу, в том числе при reduced motion.

- SSR, первый экран, переход по hash и фокус показывают содержимое сразу. Reduced motion отключает вступление.

**Адаптивность:**
- Mobile: линия слева (`left-6`), контент с отступом (`pl-14`)
- Desktop (md+): линия по центру, карточки чередуются left/right

- Семантика: `<ol>` + `<li>` для списка шагов
- Screen reader: `<span className="sr-only">Шаг N:</span>` перед заголовком
- Декоративные элементы: `aria-hidden="true"`

## Animation & Transitions

Содержательные переходы публичного сайта, диагностик и финансовой игры используют одну прямую зависимость `motion` major 12 и импорты `motion/react`. Серверные страницы, загрузка CMS и `Section` остаются серверными; клиентские границы размещаются вокруг конкретного поведения.

### Применение и доступность

- `Reveal` включается явно, а не по умолчанию в `Section`. Серверная разметка и первый экран видны. Скрывать разрешено только проверенную группу ниже viewport; hash-навигация, focus, back/forward и смена reduced motion немедленно показывают её. Не анимировать одновременно секцию и каждую её карточку.
- Общая сцена первого экрана — `shared/ui/HeroMotionScene`. Она подключена к главной, компаниям, частным лицам, центру, истории, всем страницам услуг, сезонному предложению, финансовым играм, портфолио и отзывам. Иллюстрированные hero используют одну траекторию уменьшения и ухода иллюстрации вверх; следующий блок перекрывает закреплённый hero. Фотографический вариант сохраняет стеклянную панель и двигает только фоновое фото; текстовый вариант не масштабирует заголовки. Скролл, размеры шрифтов, CMS-разметка и CTA остаются нативными.
- Главная использует эту сцену через `app/_components/HomeMotionScene` с `missionDeck`: при скролле иллюстрация hero уменьшается и уступает место белой поверхности с колодой направлений. Текст и CTA не анимируются. Перекрытый hero получает `inert` по нативному scroll; возврат фокуса раскрывает его независимо от декоративного кадра. До 1200 px нет sticky и иллюстрации, до 1280 px входит одна мобильная карточка. Подписки отключаются при скрытии вкладки, уходе сцены из viewport и reduced motion. Выбор направления завершает вступление колоды.
- Услуги собираются в bento по карточкам, продукты сходятся с двух сторон, проекты появляются по рядам. Это явный вариант `Reveal variant="card"`; прочие страницы сохраняют прежний спокойный reveal. На телефоне остаётся короткий вертикальный вход. Лимит задержек — 200 мс. Заголовки секций доступны сразу.
- Вступления главной запускаются внутри видимой области (`viewport="inset"`, по умолчанию для `variant="card"`). Порог зависит от высоты окна, а не доли высоты карточки: высокие карточки тоже входят предсказуемо. Прочие Reveal сохраняют отступ 24 px. Уже видимый при загрузке контент не прячется.
- `HeroEntrance` даёт короткое вступление видимому мобильному hero, заголовкам блога/вакансий/документов и вводным экранам диагностик: translateY 16 → 0 за 560 мс, без скрытия текста, изменения шрифта или закрепления читаемого документа. Выполняется один раз; пропускается при восстановленной прокрутке, hash, фокусе и reduced motion. В адаптивных hero выбирается только видимая версия. На главной сохраняется принятая мобильная сцена колоды.
- Partners: панели и награды входят спокойно; новая категория логотипов появляется каскадом внутри стабильной сетки, подготовка выполняется до отрисовки кадра. Названия набраны сразу в конечном размере и увеличиваются CSS-scale с 85–86% до 100%; `font-size`, переносы строк и геометрия карточки не анимируются. При reduced motion масштаб сразу 100%. Рекомендации меняются по направлению кнопки. Форма входит целиком, без отдельных анимаций полей. У новостей сначала выделяется ведущий материал, рядом последовательно появляются остальные. При hash, фокусе и reduced motion вступления завершаются немедленно.
- `ContentTransition` анимирует существующее содержимое без `key`, сбрасывающего форму. При смене шага фокус получает заголовок; прокрутка учитывает отступ шапки. `order` задаёт направление входа. В диагностиках двигается только колонка вопроса, навигация остаётся на месте. Начальная и конечная позиции заданы одним вызовом `useAnimate`, без гонки подготовки и запуска в одном кадре. Ошибки показываются сразу.
- Каталоги, портфолио, команда и сезонные задачи используют отдельный `Reveal variant="card"` на карточке. У истории, статей, вакансий и вебинаров — спокойное появление строки; у горизонтальных лент — одно вступление всей ленты. Списки `ol/ul`, grid-area и scroll snap сохраняются; родительский reveal поверх дочерних не добавляется.
- Длинные рекомендации раскрывают измеренную высоту контейнера за 300 мс. Размер шрифта и переносы не анимируются; после перехода высота снова автоматическая. Фокус на ссылке внутри обрезанного текста раскрывает его сразу.
- Формы входят одним блоком через общий LeadForm. Статьи, описания услуг и юридические тексты читаются без декоративной анимации абзацев.
- `PresencePanel` сохраняет DOM только для визуального выхода. Уходящее меню немедленно получает `inert` и `aria-hidden`; управляющий компонент возвращает фокус на кнопку. Быстрое повторное открытие не создаёт второй активной панели.
- `MotionDetails` сохраняет нативные `details/summary`, SSR-раскрытие и клавиатуру. Motion измеряет и меняет высоту только содержимого одного аккордеона. При закрытии его поля и ссылки сразу неактивны. `MotionCollapse` используется для панелей диагностик.
- `MotionProgress` использует `scaleX` с левым origin. Доступное числовое значение задаётся на родительском `progressbar` и не зависит от визуальной анимации.
- `AnimatedNumber` обновляет текст через MotionValue; отдельный текст для screen reader содержит финальное число без покадровых объявлений.
- Partners останавливает таймер и прогресс при hover, фокусе внутри, ручной паузе, reduced motion, невидимости вкладки или блока. Выбор категории явно сбрасывает цикл; завершение декоративной анимации не переключает данные.
- Пять сцен игры остаются смонтированными. `inert`, `aria-hidden`, сохранение выбора, возврат и перевод фокуса управляются существующей моделью игры; Motion отвечает за opacity и направленное смещение только активной сцены. На desktop высота игрового поля стабильна, на телефоне соответствует текущему содержимому.

`MotionConfig` недостаточно для таймеров, imperative animation и прокрутки. Для них используются живые подписки из `shared/lib/motion/preferences.ts`. При reduced motion нет параллакса, пространственных вступлений, декоративных циклов или autoplay; переходы состояний и числовой результат немедленные. Настройка применяется и при изменении на открытой странице. CSS reduced-motion правило сокращает обычные переходы; программная прокрутка использует `preferredScrollBehavior()`.

### CSS и нативное поведение

CSS сохраняется для простых hover/focus: цвет, рамка, тень, небольшое движение иконки или карточки. Один узел не должен одновременно получать Motion transform и CSS `transition-transform`, `transition-all` или hover-transform. Постоянный `will-change` для коллекций карточек не нужен.

```css
/* Кнопка */
transition: background 0.15s ease, transform 0.15s ease, box-shadow 0.15s ease;

/* Карточка без Motion transform на этом же узле */
transition: transform 0.2s ease, box-shadow 0.2s ease;

/* Ссылка и поле */
transition: color 0.15s ease;
transition: border-color 0.15s ease, box-shadow 0.15s ease;
```

Нативные scroll/snap и observer загрузки PDF в RecommendationLettersRail, измерение высоты колоды, вычисление темы шапки по sentinel и `RouteScrollBehavior` сохраняются. Юридические и длинные редакционные страницы статичны. Существующие лаборатории поддерживают общую зависимость, но их творческие сценарии не унифицируются с публичным сайтом.

## Accessibility Checklist

- [ ] Контраст текста минимум 4.5:1
- [ ] Focus-состояния видимы (не `outline: none`)
- [ ] Все интерактивные элементы доступны с клавиатуры
- [ ] Touch targets минимум 44x44px на мобильных
- [ ] Семантическая разметка (h1 → h2 → h3)
- [ ] Alt-тексты для изображений
- [ ] ARIA-labels для icon-only buttons
- [ ] Reduced motion для пользователей с vestibular disorders

## Do's and Don'ts

### Do ✅
- Используй Electric Cyan только для главных CTA
- Оставляй достаточно воздуха между элементами
- Поддерживай единую иерархию заголовков
- Проверяй контрастность текста
- Делай touch targets минимум 44px

### Don't ❌
- Не используй более 2-3 цветов на одном экране
- Не делай текст меньше 14px (кроме labels)
- Не убирай focus-состояния
- Не используй чистый чёрный (#000) для текста
- Не перегружай страницу анимациями
- Не делай Electric Cyan для всех кнопок — только primary CTA
